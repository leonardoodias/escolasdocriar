# Castelo Criar: Acolher e Educar

Crie um site institucional completo, moderno, responsivo e profissional para a Escola Castelo do Criar, uma escola de educação infantil, ensino fundamental e ensino médio localizada em Santa Rosa de Viterbo/SP, Brasil.

1. Objetivo do site

O site deve transmitir:

acolhimento;

confiança;

proximidade com as famílias;

qualidade de ensino;

desenvolvimento integral dos alunos;

inovação;

criatividade;

formação humana;

sentimento de comunidade.

O principal objetivo comercial do site é gerar interesse de novas famílias e facilitar o contato para:

conhecer a escola;

agendar uma visita;

solicitar informações;

realizar matrícula;

conversar pelo WhatsApp.

O site também deve ser útil para famílias que já fazem parte da escola.

2. Identidade visual

Utilize uma identidade visual alegre, moderna e educacional.

Paleta principal

Utilize como base:

azul;

laranja;

branco;

tons claros e suaves como apoio.

Evite excesso de cores fortes.

O design deve ser:

clean;

acolhedor;

profissional;

moderno;

com bastante espaço em branco;

com cantos arredondados;

pequenas ilustrações relacionadas à educação;

animações discretas;

excelente experiência mobile.

Utilize a logo oficial da Escola Castelo do Criar como principal referência visual.

Criar variáveis de tema para facilitar futuras alterações de cores.

3. Público-alvo

O principal público são:

pais;

mães;

responsáveis;

famílias procurando uma escola para seus filhos;

famílias de alunos já matriculados.

O conteúdo deve conversar principalmente com os responsáveis, mas transmitir visualmente que o ambiente escolar é alegre, seguro e estimulante para crianças e adolescentes.

24. Direção visual

Evite aparência de:

template genérico;

site corporativo tradicional;

excesso de texto;

excesso de animações;

desenhos infantis demais.

A escola atende desde crianças até adolescentes, portanto o design deve equilibrar:

acolhimento infantil + credibilidade educacional + modernidade.

Utilizar fotos grandes, textos curtos e boa hierarquia visual.
